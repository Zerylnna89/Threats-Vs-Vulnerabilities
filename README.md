# Threats-Vs-Vulnerabilities

Lab 1: Threats vs Vulnerabilities
1. Introduction
This repository contains notes and analysis for Lab 1, focusing on the fundamental differences between threats and vulnerabilities in cybersecurity.

2. Core Concepts
Threat
Definition: Anything—such as a person, event, or condition—that has the potential to cause harm, disruption, or loss to a system or organization by exploiting a weakness.

Simple Analogy: A burglar walking around the neighborhood looking for an open door.

Real-World Examples:
Phishing emails sent by malicious actors.
Malware or ransomware attacks.
Disgruntled employees trying to leak data.

Vulnerability 
Definition: A weakness, flaw, or error in system security procedures, design, or implementation that can be exploited by a threat.

Simple Analogy: Leaving the front door unlocked or having a weak lock.

Real-World Examples:
Outdated software containing known unpatched bugs. Example: Log4j

3. Summary / Key Difference
Threats are what we are afraid of happening (the external danger).
Vulnerabilities are the flaws inside our systems that allow those threats to succeed.
Weak, easily guessable passwords.

Misconfigured server permissions.
